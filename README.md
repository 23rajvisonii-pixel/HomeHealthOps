# HomeHealthOps – Home Health Operations & Intelligence Dashboard

This package contains the complete frontend for the **HomeHealthOps** healthcare SaaS dashboard.

## Option 1: Run Full Next.js React Application (Recommended)

### Prerequisites
- Node.js (v18.18+ or v20+)
- npm / pnpm / yarn

### Quick Start
1. Install dependencies:
   npm install

2. Run the development server:
   npm run dev

3. Open http://localhost:3000 in your browser.

---

## Option 2: Instant Browser Preview (Zero Installation)
Double-click `standalone-dashboard-preview.html` to open the complete interactive dashboard directly in any web browser (Chrome, Edge, Safari, Firefox) without needing Node.js or npm!

---

## Project Structure
- src/app/: Next.js App Router (layout, globals.css, master page)
- src/components/: Modular React components (Header, Sidebar, SummaryCard, ReferralIntake, ClinicianMatch, PrePCRSection, Modals)
- src/data/: Demonstration data models
- public/: Static assets
